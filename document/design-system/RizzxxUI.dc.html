Design System

Sistem untuk produk bisnis yang padat informasi.

RizzxxUI adalah fondasi visual untuk admin dashboard, SaaS, dan internal tools. Netral abu kebiruan, satu aksen biru, tipografi geometrik, dan kaca yang dipakai seperlunya — bukan sebagai dekorasi.

Dark & light setara WCAG AA ketat Token semantik Tailwind-ready

01 — Prinsip

Data dulu, gaya belakangan

Kalau sebuah efek visual membuat angka lebih sulit dibaca, efek itu yang pergi.

Kaca itu lapisan, bukan tema

Blur hanya di card konten dan hero. Tabel, form, dan teks panjang selalu di permukaan solid.

Satu keputusan, satu tempat

Nilai mentah tidak pernah ditulis di komponen. Semua lewat token semantik.

AA bukan target, tapi syarat

Teks minimal 4.5:1, elemen UI 3:1 — di kedua mode, termasuk di atas kaca.

03 — Tipografi

Sora untuk suara, Space Grotesk untuk kerja

Sora dipakai di heading dan angka besar — geometrik, sedikit berkarakter. Space Grotesk menangani seluruh UI: label, isi tabel, tombol. IBM Plex Mono untuk nilai teknis dan kode.

display / 52 / 600 Pendapatan
h1 / 30 / 600 Ringkasan bulanan
h2 / 22 / 600 Transaksi terakhir
h3 / 17 / 600 Metode pembayaran
body / 15 / 400 Ukuran default seluruh antarmuka. Panjang baris ideal 60–75 karakter agar tetap nyaman dibaca.
small / 13 / 400 Helper text, isi tabel padat, caption di bawah chart
mono / 13 / 400 IDR 24.850.000 · INV-2048 · 99.94%
LAKUKAN

Angka di tabel dan metrik pakai mono dengan tabular-nums supaya kolom lurus.

HINDARI

Sora untuk paragraf panjang — bentuk geometrisnya melelahkan di bawah 16px.

06 — Material & Kedalaman

Kedalaman menandai fungsi, bukan gaya

Di bawah lapisan kaca ada lapisan material: permukaan dengan bevel dan cahaya tetap dari atas. Aturannya satu kalimat — yang menonjol bisa ditekan, yang cekung bisa diisi, dan konten selalu datar. Tekstur figuratif seperti kulit, kayu, atau logam tidak dipakai; materialnya abstrak, hanya cahaya dan kedalaman.

14 — Overlay & Menu

Satu primitif, empat perilaku

19 — Serah terima

Token sebagai Tailwind config

Warna didefinisikan sekali sebagai CSS variable, lalu dipetakan ke nama semantik di Tailwind. Ganti tema cukup dengan mengubah data-theme di elemen html — tidak ada kelas dark: yang berserakan.

// tailwind.config.js
export default {
  theme: {
    extend: {
      colors: {
        surface: {
          DEFAULT: 'var(--surface)',
          raised:  'var(--surface-raised)',
          sunken:  'var(--surface-sunken)',
          inset:   'var(--surface-inset)',
        },
        border: {
          subtle: 'var(--border-subtle)',
          strong: 'var(--border-strong)',
        },
        text: {
          primary:   'var(--text-primary)',
          secondary: 'var(--text-secondary)',
          muted:     'var(--text-muted)',
          inverse:   'var(--text-inverse)',
        },
        accent: {
          DEFAULT: 'var(--accent)',
          hover:   'var(--accent-hover)',
          soft:    'var(--accent-soft)',
          on:      'var(--accent-on)',
        },
        success: 'var(--success)', warning: 'var(--warning)',
        danger:  'var(--danger)',  info:    'var(--info)',
        chart: {
          1:'var(--c1)', 2:'var(--c2)', 3:'var(--c3)',
          4:'var(--c4)', 5:'var(--c5)', 6:'var(--c6)',
        },
      },
      fontFamily: {
        display: ['Sora', 'system-ui', 'sans-serif'],
        sans:    ['Space Grotesk', 'system-ui', 'sans-serif'],
        mono:    ['IBM Plex Mono', 'monospace'],
      },
      borderRadius: { sm:'6px', md:'8px', lg:'10px', xl:'14px' },
      boxShadow: {
        sm:'var(--shadow-sm)', md:'var(--shadow-md)',
        lg:'var(--shadow-lg)', glass:'var(--glass-shadow)',
        bevel:'var(--bevel)', lift:'var(--lift)',
        press:'var(--press)', well:'var(--well)',
      },
      backgroundImage: {
        'mat-raised':'var(--mat-raised)', 'mat-base':'var(--mat-base)',
        'mat-accent':'var(--mat-accent)',
      },
      transitionTimingFunction: { rizz: 'cubic-bezier(.2,.8,.2,1)' },
    },
  },
}

Utility kaca dipakai sebagai satu kelas komponen: .glass { @apply backdrop-blur-[16px] backdrop-saturate-150 bg-[var(--glass-bg)] border border-[var(--glass-border)] shadow-glass; }
